## Decision Rule
- If 2 or more people are interested: keep the offer and improve clarity only.
- If most people are confused: narrow the headline and who-it-is-for section.
- If most people say it is too expensive: improve the promise before lowering price.
- If nobody responds: test a different audience before rewriting everything.
