Memory Doctor

Read-only workspace inspection. Counts sessions, candidates, decisions, approved stores, and context bundles.

python scripts/memory_doctor.py --dest-dir .\tmp\memory-demo --json

Demo Workspace

Creates fake transcription, ChatGPT export, and email files under the chosen destination.

python scripts/create_memory_demo_workspace.py --dest-dir .\tmp\memory-demo --apply

Health Smoke

Builds a temporary demo workspace, runs the fake-data pipeline, runs diagnostics, then cleans up.

python scripts/run_memory_health_smoke.py --json

  • No background watchers, schedulers, or server route wiring.
  • Demo writes stay under the selected destination directory.
