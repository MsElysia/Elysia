Memory first-run setup

Prepare local files, preview them, and keep every memory pending until you confirm and review it.

Before you import

  1. Create a local working folder for memory exports.
  2. Copy only files you already exported or wrote yourself into that folder.
  3. Use transcription/text files, a local ChatGPT export JSON, or local email .eml files.
  4. Keep originals outside the working folder if you want a separate backup.

Local files only. No account connection required.

Safe order of operations

  1. Open the Memory Hub.
  2. Open Import Memory and preview the intended local files.
  3. Confirm import only after reviewing the preview output.
  4. Review pending candidates before approving anything.
  5. Search only approved memories.
  6. Build a context bundle only when you explicitly need a local handoff file.

What this page does not do

This static guide does not upload files, call models, create embeddings, connect to accounts, start watchers, or write live runtime memory.

No browser network call, external asset, or server route is used by this page.
