Memory Safety

What the static Memory workflow does and does not do.

Memory Hub / Safety Local route: /memory/memory_safety.html

Safe defaults

  • Local files only.
  • No account connection required.
  • No model calls during import, review, or search.
  • No embeddings.
  • No live runtime memory or vector DB writes.
  • No server route required.
  • No background watcher.
  • No autonomy.

What is allowed

Operators can preview local transcription files, local ChatGPT export files, and local email .eml files. Imports stay pending until the operator confirms and reviews them.

Only approved memory is searchable.

What is not connected

  • No live ChatGPT account.
  • No Gmail, Outlook, IMAP, SMTP, or mailbox login.
  • No automatic folder monitor.
  • No browser network call from this page.
  • No upload from static pages.

The static pages are for orientation and prototype navigation only.
